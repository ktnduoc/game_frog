# game_frog

🐸 Frog Tongue Game - A fun web-based game where you control a frog catching insects!

## Features
- Catch various insects (flies, dragonflies, butterflies, bees, mosquitoes, fireflies)
- Progressive leveling system with increasing difficulty
- Digestion mechanics and weight management
- Special power-ups (holy water, digest potion)
- Background music and sound effects
- Mobile-friendly touch controls
- Victory animations with fireworks

## How to Play
1. Open `index.html` in a web browser
2. Click the Play button to start
3. Move your mouse to aim the frog's tongue
4. Click or press Space to shoot
5. Catch insects to gain points and level up
6. Avoid getting too heavy or starving
7. Reach the finish line to win!

## Technologies
- Pure JavaScript (ES6 modules)
- HTML5 Canvas
- Web Audio API

## Controls
- **Mouse**: Aim the tongue
- **Click/Space**: Shoot tongue
- **Mute Button**: Toggle sound on/off

Enjoy the game! 🎮
